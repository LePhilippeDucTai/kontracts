# PLAN — clean-room-core

kontract v0.3: clean-room reimplementation in pure Rust of the non-GUI core capabilities of a reference contract-algebra pricing library (numerics, dates and conventions, market data and curves, a new dated contract algebra replacing the v0.2 AST, MC/AMC/PDE engines, equity/FX/rates/credit/commodity/inflation/hybrid models with calibration, analytics), with independently derived tests covering the same behaviours as the reference test suite, migrated v0.2 features and Python bindings. The reference library is read only by dirty-room spec units; implementers work from the specs and public literature.

Protocol: 3 · Plan: `9050db78-3380-4102-aa69-cbcb313b5749` · Revision: 1

Base: `clean-room-core`
